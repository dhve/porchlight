# Sutros release, September 23, 2026

Sutros remains the community, and wekup is its website checkup feature. Claude Fable 5.1 implemented the window controls and interface changes in the original project chat. Codex implemented and integrated evidence review, image screening, community ownership and privacy protections. The production model remains gpt-5.6.

## Changes

- The wekup window can be moved, resized and made translucent. Its controls support keyboard input, and it fits the visible phone viewport. The launcher is narrower, and busy replies say Thinking.
- Checkups show a stage progress bar. Each run resets its symbols, and the security stage uses a lock.
- Loading screens receive up to seven additional seconds within the overall check budget. Reports show observed times and unresolved loading conditions.
- A final AI review checks the draft against its available evidence before scoring, signing, storing and delivering the report. It receives selected recorded response metadata and browser readiness measurements. Unsupported observations add no numeric penalty and are identified separately. If the reviewer rejects overall report claims, the grade is withheld and the report explains that decision.
- A+ requires complete coverage, a completed evidence review and no non-minor issues. Unresolved non-minor observations prevent A+. Badge colors and circle proportions match the report grade and score.
- Script errors show the recorded page, script address, line and column when available. Reports explain when the original source file or affected HTML element is unknown. Relevant technical terms have definitions.
- Checkups stay private unless their owners publish them to ask for community help. The recent public checkups section is removed. Owners can remove their posts and withdraw public report access.
- Helper listings require a verified account. Email contacts must match that account's confirmed address, and website contacts must be reachable. Account holders can remove their own helper listings.
- Content screening checks bounded page images for explicit sexual content, with a context review for positive results. Nonsexual news imagery is allowed. A failed screening attempt requests a retry rather than accusing the site of containing sexual content.
- Signing out or changing accounts clears private reports, screenshots, account lists, verification results and conversation state. Delayed responses cannot repopulate the old account's content.

## Limits

AI review can still make mistakes. Image screening samples at most three page views and cannot guarantee that every page or image is suitable for work. Rejected screening images are not stored by Sutros. The AI provider's retention rules still apply.

Loading times are observations from the checker, not promises about another device or connection. Phone layout and keyboard viewport changes are tested in Chromium; physical phone keyboards require a separate device check.

Feedback changes verification guidance and can trigger new evidence checks. It does not retrain model weights or alter original signed reports. New grading and final review apply to new checkups.

Existing helper listings without account ownership remain in the database but are hidden from the directory. Their owners can create listings from verified accounts. Existing community posts retain their prior opt-in publication.

## Deployment

The production database and configuration were backed up before deployment. The publication index migration requires stopping the old service before starting the new code. Restoring older code after this migration requires checking its database compatibility; the deployment script does not overwrite the database on failure.

The exact release revision, test results and live verification are recorded in the task's release evidence.
