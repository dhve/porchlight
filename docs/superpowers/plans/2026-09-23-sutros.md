## Global constraints

- Production AI stays gpt-5.6. Actual Claude collaboration stays in the original Fable 5.1 chat.
- Existing signed observations are immutable. Privacy is enforced outside signed report JSON.
- Page requests remain read-only, SSRF guarded and bounded. No arbitrary image URLs go to the provider.
- No source-map or HTML mapping is invented. No model review is a guarantee of correctness.
- No real explicit imagery, real mail delivery or paid model calls in automated tests.
- Root alone merges and deploys. Preserve .env and existing user data.

## Review focus

- Cross-account access through lesser-used evidence/feedback/badge routes and cooldown responses: privacy matrix tests.
- Browser loading shells and missing model output incorrectly earning A+: fixture and pipeline tests.
- A moved dialog outside a resized viewport or a stale account draft: browser controls and account tests.
- Graphic news being treated as sexual imagery or untrusted page text overriding classification: moderation contract tests.
- Public post removal leaving a cached badge or leaked report accessible: access/cache/soft-delete tests.

2. Extend chatJSON with optional timeoutMs using one total deadline across retry, retaining 90000 ms default and multimodal content arrays.

4. Add contentScreening module that consumes captured image bytes. Use the sexual image category only; ignore broad flagged/violence. Positive samples receive bounded context review. Invalid provider replies are unavailable, not allowed or denied by guess.
