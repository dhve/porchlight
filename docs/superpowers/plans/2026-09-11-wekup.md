# wekup implementation plan

> Agentic workers use the execution and review workflow, with Claude handling the backend in the user's original chat and Codex handling the frontend and release.

**Goal:** Put the Sutros community first and add a working wekup conversation with evidence checks, live reassessments and automatic feedback guidance.

**Architecture:** A vanilla JavaScript popup uses private authenticated conversation routes. Durable backend jobs verify stored evidence and publish safe assessments separately from signed reports. The existing automatic feedback system supplies canonical guidance to future scans.

**Tech stack:** Node 22.23.2, Express, PostgreSQL 16, vanilla HTML/CSS/JavaScript, Playwright.

**Spec:** ../specs/2026-09-11-wekup.md. Shared API and backend ownership: external work/wekup-contract.md.

## Global constraints

- Sutros is the community; wekup is its lowercase AI feature name.
- Keep signed report evidence, grade and signature unchanged.
- Require verified accounts for processing; private chat is account-bound.
- No raw chat text in public assessments or future checkup prompts.
- Use existing hosting, account and model configuration.
- Root owns public files and server/index.js; Claude owns server/wekup*.js and focused backend tests.
